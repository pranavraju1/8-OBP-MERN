Virtual DOM
its a lightwieght JS representation of the Real DOM.
Instead of immediately changing the Browser DOM, React creates a Virtual copy
The copy exits entirely in the memory

# Working of VOD

1. <h1>Hello</h1>

2. React creates a copy
{
    type: "h1"
    children: ["Hello"]
}

3. Later the State changes react creates a new VOD
{
    type: "h1"
    children: ["Hello World"]
}

4. The 2 DOM's that are created are now compared -> it detects that the text "Hello" changes to "Hello world"
5. it Will only update that particular part of the Real DOM


Diffing -> Its process where the Two DOMs are compared with each other to find the difference between them

Reconciliation -> Its an algorithm that react uses to update the Real DOM 
after finding the difference using Diffing

# the full rendering process

State changes   ->  New VOD ->  Diffing ->  Reconciliation  ->  Real DOM (changes reflected) 

React Fibre -> Home Work
